# FinTrack

Personal finance management app built with Flutter & Firebase.

## Tech Stack
- Flutter (Dart) + Riverpod
- Firebase (Auth, Firestore, Storage)
- Clean Architecture (feature-based)

## Status
🚧 In development — project setup complete, features in progress.

## Getting Started
1. `flutter pub get`
2. `flutterfire configure` (butuh akses Firebase project sendiri)
3. `flutter run`
